Decisions, gaps and unverified points, verbatim and in full under "Every finding" below. In
short:

- `install-cli` links into `/usr/local/bin` only for a binary it placed in the data dir, never
  for a `RELEASE_CLI` or PATH hit (`bi5.1#1`). The delta said "link the binary" without saying
  for which lookup outcomes.
- The delta's cause/remedy table has five rows, and the script has seven more failure points.
  The dispatch chose a message and remedy for each, and left it to the DoD bead to decide which
  become criteria (`bi5.1#2`).

  delta listed (`bi5.3#2`).
- The SKILL section pointers were deferred from `.2` to `.3` because `check-skills.sh` rule 2
  fails an unresolved `*.md` path (`bi5.2#1`, `bi5.3#3`).
- Every CLI behaviour the skill states was taken from `testdata/help/*.txt` or
  `internal/bump/bump.go`. No `.claude/skills/cut-release` symlink was added (`bi5.2#3`).
- `propagate-version.sh` validates both files before writing either, and hard-codes the `v` tag
  prefix (`bi5.4#2`).
- `internal/pluginscripts` carries a `doc.go` so coverage lists it (`bi5.1#7`).
- A manifest with two top-level `version` keys fails rather than taking the first (`bi5.9#2`).

  harness so its reintroduction fails every run (`bi5.13#2`).
